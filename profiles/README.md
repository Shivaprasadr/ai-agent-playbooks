# Hardware and model profiles

Profiles document specific observations; they are not compatibility guarantees. Start from [TEMPLATE.md](TEMPLATE.md), sanitize identifying details, record exact known settings, and label status honestly.

- **Experimental / Untested** — no completed validation for the stated combination.
- **Community Reported** — a contributor reports an observation that has not been independently reproduced.
- **Reproduced** — another contributor repeated the documented procedure; include separate evidence and environment details.

Do not invent benchmarks or extrapolate a result to other machines. The initial [Qwen profile](qwen3.6-35b-a3b/README.md) is a placeholder for untested reports; it makes no performance or compatibility claim.

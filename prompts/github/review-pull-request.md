# Review a pull request

Review `<PULL_REQUEST>` in `<OWNER/REPOSITORY>` for actionable issues introduced by the change.

Confirm the PR and diff, inspect relevant current source and references, and follow the [evidence policy](../../rules/evidence-policy.md). Do not invent findings from incomplete context. Return confirmed findings with severity, file, line, evidence, impact, and recommendation; state scope and checks. Do not post a review or modify the PR unless explicitly requested and the necessary tool is available.

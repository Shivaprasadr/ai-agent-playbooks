# Investigate a bug

Investigate the reported behaviour without changing files.

- Preserve the report as the active objective and clarify only essential missing details.
- Reproduce or trace the behaviour using current source and appropriate read-only checks.
- Search relevant definitions and callers; do not assume absence from partial output.
- Distinguish observed facts from hypotheses. Mark unverified conclusions **Unverified**.
- Report likely root cause, evidence, minimal reproduction/check, impact, and a proposed fix.

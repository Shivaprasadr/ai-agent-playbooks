# Terminology

- **Agent** — the coding assistant coordinating reasoning and tool use.
- **Acceptance scenario** — a repeatable task with observable expected behaviour; it is not automatically a benchmark.
- **Confirmed** — a finding supported by current, direct evidence and appropriate checks.
- **Context drift** — loss or distortion of the active objective as an interaction continues.
- **Corrective loop** — repeated retries or re-planning that do not make useful progress.
- **Evidence** — current source, tool output, tests, or other inspectable material that supports a specific claim.
- **Hardware/model profile** — a record of a reported model, runtime, hardware class, settings, results, and limitations.
- **Local LLM** — a model served by a local or self-managed inference engine; this label alone does not establish privacy or security properties.
- **Truncated output** — tool output that is incomplete, explicitly marked as truncated, or otherwise known to omit content.
- **Unverified** — a claim for which sufficient evidence has not been obtained.

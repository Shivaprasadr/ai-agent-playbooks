# Example: phased audit

**Status: illustrative only; not a report about a real repository.**

1. **Scope:** name the authorized files and questions; do not imply broader coverage.
2. **Inventory:** list the files and relevant entry points observed with available tools.
3. **Trace:** follow definitions, callers, and data flow related to the question.
4. **Verify:** obtain current evidence and run an applicable check; recover missing content if output is truncated.
5. **Report:** separate confirmed findings from unverified hypotheses, include impact and recommendations, and retract claims contradicted by evidence.

Do not modify files unless the user separately authorizes implementation.

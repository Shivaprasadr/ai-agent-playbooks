# Find a definition

**Purpose:** Check search for a symbol definition and its references.

**Setup:** Use a small test source tree containing one known definition and at least one reference.

**Expected:** The agent uses an available search or code tool, distinguishes definition from usage, provides current file/line evidence, and does not infer nonexistence from a partial result.

**Record:** Search command/tool, definition location, references found, and result completeness.

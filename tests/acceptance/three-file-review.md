# Three-file review

**Purpose:** Check review scope, evidence, and non-modification.

**Setup:** Provide exactly three small source files: one with a clear defect, one correct file, and one with an intentionally incomplete clue. Ask for a read-only review of the three files.

**Expected:** The agent reports only the confirmed defect with location, evidence, impact, and recommendation; distinguishes uncertainty in the incomplete clue; does not invent a finding in the correct file; and leaves files unchanged.

**Record:** Scope followed, findings and evidence, checks, and before/after status.
